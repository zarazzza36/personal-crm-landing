# Лендинг «Волки с Лизюкова»

Одностраничный сайт личной CRM для логистов. Все кнопки «Перейти в приложение» ведут на https://app.volki-lzkv.ru

## Как запустить у себя

Нужны Node.js 22+ и pnpm.

```sh
pnpm install     # один раз: скачать зависимости
pnpm dev         # сайт с автообновлением: http://localhost:4321
pnpm build       # собрать готовый сайт в папку dist/
pnpm preview     # посмотреть собранный сайт
```

## Где что лежит

- `src/components/` — блоки страницы: шапка, «Проблема», «Решение», «Выгода», призыв, подвал
- `src/styles/tokens.css` — цвета, шрифты, размеры текста, отступы
- `src/config.ts` — адрес приложения для кнопок
- `src/assets/fonts/` — шрифты Unbounded и IBM Plex Mono (лицензия OFL, файлы рядом)
- `design/` — макет: образец того, как должна выглядеть страница
- `public/og-image.png` — картинка для превью ссылки в мессенджерах и соцсетях. Это снимок страницы `design/og-image.html`: как его пересобрать, написано в начале этого файла. Та же картинка лежит в приложении — при замене поменять и там
- `src/layouts/Base.astro` — заголовок, описание и теги превью ссылки (`og:*`)
- `.github/workflows/deploy.yml` — выкатка на сервер
- `deploy/server/` — разовая настройка сервера под лендинг

## Как выкатить новую версию

Отправить изменения в ветку `main` (`git push`). Дальше всё делает GitHub Actions: собирает сайт, копирует его на сервер и проверяет, что https://volki-lzkv.ru отвечает и отдаёт новую версию. За ходом выкатки можно следить на вкладке Actions в репозитории. Если выкатка упала, на сайте обычно остаётся прошлая версия (если сбой случился посреди копирования — смесь старой и новой): исправляем и отправляем снова.

Настройки в GitHub (Settings → Secrets and variables → Actions):

- секрет `DEPLOY_SSH_KEY` — ключ, с которым GitHub заходит на сервер. Этот ключ умеет только складывать файлы в папку сайта
- переменные `DEPLOY_HOST` (адрес сервера) и `DEPLOY_KNOWN_HOSTS` (ключи сервера, чтобы GitHub не попал на чужую машину)

Сервер настраивается один раз скриптом `deploy/server/setup-landing.sh`: он ставит rsync, заводит пользователя `landing` с папкой `/var/www/volki-lzkv.ru` и переключает nginx с заглушки на эту папку. Настройки приложения скрипт не трогает.

# Лендинг «Волки с Лизюкова»

Одностраничный сайт личной CRM для логистов. Все кнопки «Перейти в приложение» ведут на https://app.volki-lzkv.ru

## Как запустить у себя

Нужны Node.js 22+ и pnpm.

```sh
pnpm install     # один раз: скачать зависимости
pnpm dev         # сайт с автообновлением: http://localhost:4321
pnpm build       # собрать готовый сайт в папку dist/
pnpm preview     # посмотреть собранный сайт
```

## Где что лежит

- `src/components/` — блоки страницы: шапка, «Проблема», «Решение», «Выгода», призыв, подвал
- `src/styles/tokens.css` — цвета, шрифты, размеры текста, отступы
- `src/config.ts` — адрес приложения для кнопок
- `src/assets/fonts/` — шрифты Unbounded и IBM Plex Mono (лицензия OFL, файлы рядом)
- `design/` — макет: образец того, как должна выглядеть страница
